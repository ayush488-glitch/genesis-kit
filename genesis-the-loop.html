Genesis
v2 · local first
Human × AI software factory

Build with memory. Ship with proof.

Genesis turns any repository into a durable, inspectable development environment—from specification and research to implementation, verification, and the next cold session.

$ genesis adopt ./project review the discovery report $ genesis adopt ./project --write state → task → proof → checkpoint
The operating loop

One path from intent to evidence.

01

Specify

Capture the objective, constraints, assumptions, and accepted decisions.

02

Index

Map files, symbols, imports, packages, and unresolved relationships.

03

Build

Work on one bounded outcome with explicit scope and risk.

04

Prove

Bind executable evidence and independent review to current sources.

05

Resume

Generate the exact state, blocker, evidence, and next action.

Factory surfaces

Small system. Complete trace.

Repository memory

A single canonical JSON ledger preserves tasks, decisions, assumptions, invariants, evidence, failures, and durable knowledge.

Graphical code index

Deterministic JSON, DOT, and searchable HTML views use qualified identities and honest confidence metadata.

Human control

Pause, resume, reject, requeue, review, and rollback requests become auditable events. Learned rules never promote themselves.

Cold-session handoff

KICKOFF.md lets another human or agent continue without replaying old chats or reading the whole repository.

Fail-closed proof

Missing, failed, pending, or stale mandatory evidence blocks completion. Medium-risk work adds independent review automatically.

Local observability

A generated dashboard shows current work and redacted traces while raw events remain local and git-ignored.

Default policy

Ponytail, full.

The factory prefers the standard library, reuses what exists, and creates only what the current evidence requires.

  • One operational source of truth
  • Zero runtime package dependencies
  • No silent code deletion or rule promotion
  • No fake semantic or runtime claims
  • No prior conversation required to resume
