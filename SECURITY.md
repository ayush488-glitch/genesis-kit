# Security

Genesis runs project-supplied commands with the host user's permissions. A repository, worktree or temporary evaluation directory is not a sandbox. Protect credentials, network access, evaluators and holdouts through the host environment. Review names are attribution rather than authentication.

Do not put credentials, private transcripts or working exploits in a public issue. Use GitHub's private vulnerability-reporting route if it is available on the repository's Security tab. Otherwise, open a minimal issue requesting a private contact channel without disclosing exploit details.

Reports should identify the affected version/commit, trust boundary, minimal reproduction and expected impact. We do not currently promise a response SLA or maintenance of older release lines. Use the current release and inspect migration notes when upgrading.
